# 🚀 Demo CI/CD

Bienvenido a este proyecto de demostración de **Integración Continua y Despliegue Continuo**.

## ✨ Características

- 🐳 Docker pre-instalado
- 🔧 Herramientas CLI listas para usar
- 📦 Gestión de contenedores integrada
- 🐧 Basado en Ubuntu 24.04.3 LTS

## 🛠️ Herramientas Disponibles

| Herramienta | Descripción |
|-------------|-------------|
| `docker`    | Gestor de contenedores |
| `git`       | Control de versiones |
| `curl`      | Descargas y solicitudes HTTP |
| `ssh`       | Conexión remota segura |

## 📋 Primeros Pasos

```bash
# Clonar un repositorio
git clone <url>

# Ejecutar un contenedor
docker run -it ubuntu:latest bash

# Descargar archivos
curl -O https://ejemplo.com/archivo
```
